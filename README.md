# 🌊 Inundae – Flood Detection Platform

**Inundae** is a nonprofit initiative that leverages technology to help at-risk communities prepare for and respond to floods. Through real-time alerts and interactive educational tools, our platform empowers people in flood-prone regions to stay safe.

🚀 **Live Site**: [https://aryan158048.github.io/Inundae/](https://aryan158048.github.io/Inundae/)

---

## 🔍 About

This project includes:
- Real-time flood alert simulations
- Awareness-driven interactive games
- Volunteer sign-up and community support tools
- Educational content on regional flood impacts

---

## 📂 Tech Stack

- HTML, CSS, JavaScript
- PHP (for local form processing)
- GitHub Pages (for static deployment)

> ⚠️ Note: PHP-based form handling will not work on GitHub Pages. Use a backend (e.g., Replit, Render, Firebase) if needed.
